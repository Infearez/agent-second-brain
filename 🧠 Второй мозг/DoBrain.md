# DoBrain

#dobrain #второй_мозг #бот

## Что это

DoBrain — новая система второго мозга и будущий Telegram-бот, который должен принимать мысли, задачи, идеи, дневниковые записи и команды, а затем раскладывать их по базе.

## Основные принципы

- Не переносить старую архитектуру бота как основу.
- Использовать старую базу как источник знаний, правил и сценариев.
- Всё непонятное складывать во [[Разобрать]] с тегом #разобрать.
- Для чайного учёта использовать отдельный модуль [[Чайный бот]].
- Новые операции бота писать в рабочие журналы vault, чтобы Obsidian оставался читаемой основной базой.
