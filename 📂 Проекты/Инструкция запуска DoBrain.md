## Как система работает

- `@DoBrainVaultBot` живёт на VPS и работает через `systemd`.
- Бот пишет новые записи в серверный vault: `/home/dobrain/DoBrainVault`.
- Syncthing синхронизирует серверный vault с Mac: `/Users/infearez/Documents/Codex/DBcode`.
- Obsidian открывает локальную папку на Mac и видит свежие записи автоматически.
- Секреты лежат только в `/home/dobrain/dobrain-bot/.env` и не должны попадать в GitHub или Obsidian.

## Быстрая проверка

1. В Telegram написать боту `/status`.
2. Написать `/tea` и проверить кнопки.
3. Написать `задача проверить Dual Brain`.
4. Написать `идея: сделать быстрый чайный отчёт`.
5. Написать `дневник сегодня проверил систему`.
6. Проверить, что записи появились в Obsidian.
7. Если тестировали продажу, после теста написать `отмена продажи`.

## Проверка на VPS

```bash
systemctl is-active dobrain-bot
systemctl is-active syncthing@dobrain
journalctl -u dobrain-bot --no-pager -n 50
```

## Перезапуск бота

```bash
systemctl restart dobrain-bot
journalctl -u dobrain-bot -f
```

## Обновление кода

1. Изменить код локально.
2. Запустить тесты:

```bash
PYTHONPYCACHEPREFIX=/private/tmp/dbrain_pycache python3 -m unittest discover -s dobrain-bot/tests
```

3. Сделать commit и push.
4. Обновить код на VPS.
5. Перезапустить `dobrain-bot.service`.

## Что умеет текущий MVP

- `/start` — проверка доступа.
- `/status` — статус vault, каталога и оплат.
- `/tea` — чайное меню с кнопками.
- `/payments` — ближайшие оплаты.
- `/today` — дневник за сегодня.
- `/tasks` — файл задач.
- `продажа белый чай 8г` — добавить продажу.
- `отмена продажи` — отменить последнюю активную продажу.
- `исправь продажу тегуаньинь 10г` — отменить последнюю и записать новую.
- `задача ...`, `идея ...`, `дневник ...` — разложить запись по разделам.
- Любой непонятный текст — сохранить во [[📥 Входящие]] с тегом #разобрать.

## Что делать при проблемах

- Если бот молчит — проверить `systemctl is-active dobrain-bot`.
- Если бот отвечает, но Obsidian не видит записи — проверить Syncthing.
- Если запись не распознана — искать её во [[📥 Входящие]].
- Если продажа спорная — она должна получить #разобрать, а историю нельзя удалять руками без причины.
