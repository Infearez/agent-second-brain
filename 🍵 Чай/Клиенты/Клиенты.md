# Клиенты

#чай #клиенты #разобрать

Связанные заметки: [[Tea Bag]], [[Чайный бот]], [[Чайный_учёт]], [[Продажи чая]].

Структурированные карточки клиентов чайного магазина в архиве не найдены.

Найдены только косвенные данные:

- продажи чая без имени клиента;
- Telegram-команды о продажах;
- планы продавать через канал Tea Bag.

Для нового чайного модуля нужно добавить поле клиента как необязательное: имя, Telegram, заметка, история покупок.
